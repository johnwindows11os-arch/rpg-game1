
# Security Policy 🛡️

Thank you for helping to keep Loot Loop RPG safe and stable! We take security issues seriously and appreciate your help in reporting them.

## Supported Versions

We currently only support security updates for the latest code branch available on this repository.

| Version | Supported          |
| ------- | ------------------ |
| rpg game.py   ✅ Yes         |
              

## Reporting a Vulnerability

If you find a security bug, a way to crash the game unexpectedly, or an exploit that breaks the game loop, please let us know so we can fix it!

### How to report:
1. **Do not open a public Issue** for critical exploits or crashes right away, as this lets everyone see how to break the game before it is fixed.
2. Instead, please contact the repository owner directly or create a draft security advisory via GitHub if you have the permissions.
3. Include as much detail as possible:
   * What steps did you take to trigger the bug?
   * What Operating System are you using (Windows, Ubuntu, Arch, etc.)?
   * Any error messages or log outputs from your terminal.

We will try to review your report and push a fix or a new code version as quickly as possible!

## Safe Practices for Players

Because this game runs as a raw Python script (`.py`), always make sure you are downloading the code directly from this official GitHub repository. 

* Only download at the officcal github page.
* Never download or run copies of this file from untrusted third-party websites.
* Running scripts from unknown sources can be dangerous for your computer! Keep your Python environment secure.
